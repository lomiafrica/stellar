# SEP-6 and SEP-38

Programmatic XOF deposit/withdraw and firm quotes. Hosted next to SEP-24.

Peg: 1 EUR = 655.957 XOF. `EUR_USD_RATE` is USD per 1 EUR (default 1.08). Spread is `QUOTE_SPREAD_BPS` (default 50).

```bash
# Firm quote (TTL 60s)
curl -sS -X POST "$PUBLIC_BASE_URL/anchor/sep38/quote" \
  -H "Content-Type: application/json" \
  -d '{"sell_asset":"iso4217:XOF","buy_asset":"stellar:USDC","sell_amount":"65596"}'

# Use the quote
curl -sS -X POST "$PUBLIC_BASE_URL/anchor/sep6/withdraw" \
  -H "Content-Type: application/json" \
  -d '{"amount":"65596","quote_id":"q_…","rail":"wave","phone":"+2250700000000"}'
```

An expired `quote_id` returns 400. Replay the same body after expiry to confirm the reject.
