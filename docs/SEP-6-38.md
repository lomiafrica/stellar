# SEP-6 and SEP-38

Programmatic XOF deposit and withdraw, and firm XOF/USDC quotes. Anchor Platform serves `/sep6` and `/sep38`. The lab serves `GET /anchor/rate` when the platform asks for a price.

Peg: 1 EUR = 655.957 XOF. `EUR_USD_RATE` is USD per 1 EUR (default 1.08). Spread is `QUOTE_SPREAD_BPS` (default 50). A firm quote includes `id` and `expires_at`. An expired `quote_id` is rejected. A quote that is still valid settles at `buy_amount`, not at a new price.

`TRANSFER_SERVER` and `ANCHOR_QUOTE_SERVER` in the public toml point at the anchor host.

Replay against the public anchor:

```bash
pnpm sep6:replay
```

The same steps by hand:

1. Read the toml and take `WEB_AUTH_ENDPOINT`, `TRANSFER_SERVER`, `ANCHOR_QUOTE_SERVER`, and `SIGNING_KEY`.

```bash
curl -sS "$LAB/.well-known/stellar.toml"
```

2. SEP-10. Request a challenge for a testnet account, sign it, and post it back. The response `token` is the bearer token for the next calls.

```bash
curl -sS "$WEB_AUTH_ENDPOINT?account=$ACCOUNT&home_domain=$HOME_DOMAIN"
curl -sS -X POST "$WEB_AUTH_ENDPOINT" \
  -H "Content-Type: application/json" \
  -d '{"transaction":"<signed challenge xdr>"}'
```

3. Indicative prices, then a firm quote.

```bash
curl -sS "$ANCHOR_QUOTE_SERVER/prices?sell_asset=iso4217:XOF&sell_amount=65596&buy_asset=stellar:USDC:$USDC_ISSUER" \
  -H "Authorization: Bearer $TOKEN"

curl -sS -X POST "$ANCHOR_QUOTE_SERVER/quote" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"context":"sep6","sell_asset":"iso4217:XOF","buy_asset":"stellar:USDC:'"$USDC_ISSUER"'","sell_amount":"65596"}'
```

4. Deposit and withdraw. Use the `id` from the quote.

```bash
curl -sS "$TRANSFER_SERVER/deposit?asset_code=USDC&account=$ACCOUNT&amount=10&quote_id=$QUOTE_ID" \
  -H "Authorization: Bearer $TOKEN"

curl -sS "$TRANSFER_SERVER/withdraw?asset_code=USDC&account=$ACCOUNT&amount=10&quote_id=$QUOTE_ID" \
  -H "Authorization: Bearer $TOKEN"
```

5. Read the transaction the deposit created.

```bash
curl -sS "$TRANSFER_SERVER/transaction?id=$TX_ID" \
  -H "Authorization: Bearer $TOKEN"
```

The lab also keeps `POST /anchor/sep38/quote` and `POST /anchor/sep6/:kind` for the sandbox last mile. The platform rate callback is `GET /anchor/rate` and requires the callback API key.
